# StudyVault Engineering & Product Roadmap (v1.0.0+)

The StudyVault roadmap outlines planned engineering milestones beyond the **Version 1.0.0 Stable Public Release**.

---

## 🔷 Milestone 1: Version 1.1 — Multi-Platform Client Ecosystem
- **Desktop Application (Flutter Desktop)**: macOS, Linux, and Windows desktop apps with background seeding daemon support.
- **Web Client (Wasm / WebRTC)**: Browser-based node implementation enabling zero-install academic resource discovery.
- **Institutional Node Infrastructure**: One-click deployment templates for university libraries and research institutions.

---

## 🔷 Milestone 2: Version 1.2 — Federated Trackers & Swarm Mesh
- **Multi-Tracker Federation**: Decentralized tracker synchronization protocol allowing independent trackers to relay seeder states.
- **IPFS Cluster Integration**: Dedicated IPFS pinning cluster nodes for permanent archiving of open-access literature.
- **Community Provider SDK**: SDK for universities and publisher repositories to auto-index open metadata.

---

## 🔷 Milestone 3: Version 1.3 — Collaborative Knowledge Mesh
- **Decentralized Study Groups**: P2P shared annotation layers and reading circles.
- **Advanced Semantic Search**: On-device vector embeddings and natural language literature search.
- **Plugin Architecture**: Custom extensions for PDF annotation, LaTeX citation export, and Zotero sync.
